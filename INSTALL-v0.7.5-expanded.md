# CHB v0.7.5 — Global Panel System Expanded

Paczka rozszerza działający pilot przed commitem.

## Zmiany

- zwijane Ustawienia tygodnia,
- zwijana Historia tygodni,
- zwijany Plan finansowy,
- zapamiętywanie stanu każdego panelu lokalnie,
- selektor tygodnia oraz przyciski Nowy/Usuń pod oznaczeniem tygodnia w nagłówku,
- Historia tygodni przeniesiona pod główny układ, aby zmniejszyć wysokość i chaos kolumn.
